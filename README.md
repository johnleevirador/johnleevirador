# Hey, I'm John! 👋

### Welcome to my little corner of GitHub! 

You'll probably find a mix of projects here. Some might be practical, some might be experiments, and some might exist because I had a thought at 2 AM and refused to let it go.

I don't really stick to one thing. One day I'm messing around with microcontrollers and electronics, the next I'm building a web application, and then suddenly I'm writing a C++ library because I don't like how something works. 😂

## 🔧 Things I mess around with

- **Embedded Systems** — Microcontrollers, electronics, hardware, and making software interact with the physical world. There's something really cool about writing code and watching an actual machine respond to it.
- **Web Development** — Building websites, applications, APIs, backend systems, and whatever else an idea needs.
- **Mobile Development** — Turning ideas into applications that people can actually use.
- **C & C++** — Getting closer to the hardware, exploring how things work underneath, and occasionally questioning my life choices.
- **Libraries & Abstractions** — Probably one of my favorite things to build. Why keep solving the same complicated problem when I can make a tool that handles it for me?

I'm not particularly loyal to one area of development. If I need to learn something new to build an idea, then I guess I'm learning something new.
